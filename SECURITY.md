# Güvenlik

Bu proje tek işletim sistemi kullanıcısı için yerel bir geliştirme aracıdır.
Aynı kullanıcı altında çalışan kötü niyetli süreçlere karşı izolasyon veya
çok kiracılı güvenlik sağlamaz. İzin tavanı varsayılan olarak salt okunurdur.
`full-access` yalnızca güvenilen görevlerde açıkça seçilmelidir.

Bir güvenlik açığı bulursanız hassas ayrıntıları public issue içine koymayın.
GitHub reposunun Security → Report a vulnerability bölümünden özel bildirim
gönderin. Bildirime sürüm, etki ve kişisel veri içermeyen yeniden üretme adımları
ekleyin. Desteklenen düzeltme hedefi en son yayımlanan sürümdür.
